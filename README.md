# Customer Churn Analysis using SAS

Entry-level Data Science project analyzing customer churn patterns using SAS. This project demonstrates data import, cleaning, exploratory analysis, and reporting.

## Project Overview
This project explores customer churn behavior to identify key factors influencing customer retention. The analysis was performed in SAS, with datasets provided in multiple formats for accessibility.

**Objective**: Import, clean, and analyze churn data to generate insights and visualizations summarized in the final report.

## Repository Contents
| File | Description |
| --- | --- |
| `churn_dataset_csv.csv` | dataset in CSV format |
| `churn_dataset_excel.xlsx` | dataset in Excel format |
| `churn_dataset_txt.txt` | dataset in TXT format |
| `grand_Prjct.sas_` | SAS code for data import, cleaning, analysis, and visualization |
| `final_report.pdf` | Final project report with results, insights, and charts |

## Tools & Skills Used
- **SAS**: Data step, PROC IMPORT, PROC FREQ, PROC MEANS, PROC SGPLOT
- **Data Analysis**: Data cleaning, Exploratory Data Analysis (EDA), Summary statistics
- **Documentation**: Technical reporting

## How to Run This Project
1. **Download the files**: Clone this repo or download as ZIP
2. **Open SAS**: Use SAS Studio, SAS Enterprise Guide, or SAS OnDemand for Academics
3. **Update file paths**: In `grand_Prjct.sas_`, change the `INFILE` or `PROC IMPORT` path to match your local dataset location
4. **Run the code**: Execute `grand_Prjct.sas_` in SAS to reproduce the analysis
5. **View results**: Check the output and compare with `final_report.pdf`

Note: GitHub does not run SAS code. You must run `.sas` files locally in a SAS environment.

## Key Insights
See `final_report.pdf` for full findings, including churn rates by segment and key predictive factors.
